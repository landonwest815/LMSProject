# LMSProject

A lightweight Learning Management System (LMS) built using C# and ASP.NET Core. This project includes backend logic for managing users, courses, and assignments, along with unit tests for controller functionality.

---

## 📁 Project Structure

- `LMS/` — Core application logic
- `LMSControllerTests/` — Unit tests for controllers
- `LMS.sln` — Visual Studio solution file

---

## ✅ Features

- User authentication and role management
- Course and assignment CRUD operations
- Controller-based routing
- Unit testing

---

## 🚀 Getting Started

### Prerequisites

- [.NET SDK 7+](https://dotnet.microsoft.com/en-us/download)
- Visual Studio 2022+ or JetBrains Rider (optional)

### Build & Run

```bash
dotnet build
dotnet run --project LMS
```

### Run Tests

```bash
dotnet test
```
